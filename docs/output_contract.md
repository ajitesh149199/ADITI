# ADITI Output Contract

## 1. Purpose

The output contract defines the structure of information generated by the ADITI processing system.

It separates the decision made by the system from the physical method used to communicate that decision.

---

## 2. Output Types

ADITI supports three primary output types:

- Audio
- Haptic
- Visual

---

## 3. Audio Output

Audio output is used to communicate information through speech or sound.

Possible information includes:

- Detected objects
- Recognized text
- Important warnings
- Navigation information
- System notifications

Required fields:

- Message
- Priority
- Timestamp
- Source
- Output type

---

## 4. Haptic Output

Haptic output is used for immediate alerts.

Required fields:

- Alert type
- Priority
- Intensity
- Duration
- Timestamp

Haptic feedback should primarily be used for important or immediate events.

---

## 5. Visual Output

Visual output is mainly used for development and monitoring.

It can display:

- Camera feed
- Detected objects
- Confidence values
- Sensor values
- GPS information
- Current system state
- Alerts

---

## 6. Priority Levels

Each generated event must have a priority.

### HIGH

Important or immediate information.

### MEDIUM

Relevant environmental or contextual information.

### LOW

General information that does not require immediate attention.

---

## 7. Output Selection

The decision module determines which output should be generated.

The output may be selected according to:

- Event priority
- Event type
- Confidence
- Distance
- Urgency
- Current system state

---

## 8. Duplicate Output Prevention

Repeated events should not continuously generate the same feedback.

The system should use:

- Event cooldown
- Duplicate detection
- Priority filtering
- Confidence threshold

This helps reduce excessive audio and haptic feedback.

---

## 9. Output Validation

Before generating output, the system must verify:

- Valid message
- Valid priority
- Valid output type
- Valid timestamp
- Valid duration where applicable
- Valid intensity where applicable

Invalid output events must be rejected.
